## ⛓️ Web3

### [BasePulse](https://github.com/3dwrd/BasePulse) · [en vivo](https://basepulse.botsniper.xyz)
App de utilidad para el ecosistema Base, gratuita y en producción:
- **Portafolio:** saldos de tokens y posiciones DeFi de cualquier wallet.
- **Gas:** historial de 7 días con señal de "buen momento para transaccionar" por percentiles.
- **Score:** reputación onchain desglosada, con tarjetas para compartir.
- **Snapshot:** registro onchain del portafolio con contrato propio `PortfolioSnapshot`, verificado en Base Mainnet.

`Next.js 16` `TypeScript` `wagmi/viem` `SIWE` `Solidity/Foundry` `Redis`

Todo es EVM estándar, portable a otras L2 como **Arbitrum**.
